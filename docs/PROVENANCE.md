# Provenance

`tgzterminal` is rebuilt as a clean public fork from upstream WezTerm commit
`8afe0ad30739c5aa106c19e8a75b1dfc83bcfb56`.

The rebuild uses:

- upstream WezTerm source and license notices
- the behavior-only spec in `docs/TGZTERMINAL_REBUILD_SPEC.md`
- public Rust, Cargo, and platform documentation as needed

The rebuild does not use company source code, private tickets, internal design
documents, secrets, customer data, proprietary assets, or patches copied from a
prior prototype.
